# Dodis_PSE
This repository contains a spaCy-based pipeline for **entity linking** on TEI-XML documents.
It is designed for TEI files where entities are already annotated with `persName`, `placeName`, `orgName`.
The pipeline can be trained and evaluated using Dodis TEI-XML documents which are available on Hugging Face (see documentation).
